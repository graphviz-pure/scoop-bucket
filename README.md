# graphviz-pure Scoop bucket

```powershell
scoop bucket add graphviz-pure https://github.com/graphviz-pure/scoop-bucket
scoop install graphviz-pure/graphviz-pure
```

The manifest is regenerated by `.github/workflows/update.yml` from each graphviz-pure release, after verifying every asset's build-provenance attestation and checksum. graphviz-pure is an independent port of Graphviz, not affiliated with the Graphviz project.

From the first release carrying x86-64-v3 and `-compat` archives, x86-64 installs
use a baseline Rust launcher with `v3/graphviz-pure[.exe]` and
`compat/graphviz-pure[.exe]`. Both archives are verified before installation;
CPUs without AVX2/FMA use compat automatically. Existing releases without a
launcher retain their baseline-only installation. ARM64 is unchanged.
